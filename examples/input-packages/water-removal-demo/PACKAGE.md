# 原始包说明：污水处理中的污染物去除率

这组资料是一份人工编写的教学方法说明，以及三条合成的进出水记录，适合探索单位换算、污染物负荷计算与边界处理相关的科学 coding 任务。它们不是外部论文或真实观测数据。

## 资料

- [方法说明](materials/method.md)：描述稳态教学假设、流量与浓度单位，以及负荷和去除率公式。
- [示例数据](materials/measurements.csv)：flow_m3_day 为流量，inlet_mg_l 与 outlet_mg_l 为进出水浓度。数据与方法说明采用相同单位。

## 已知情况

数据量很小，其中有零进水浓度案例。缺失值、零浓度与非法输入应如何处理，目前未定义为任务要求，可由出题者根据目标设计并明确说明。

这些材料可用于本项目的教学和任务构造。需要时可以补充来源或设计合成输入，但应注明新增内容，不能将合成数据说成实测数据。
